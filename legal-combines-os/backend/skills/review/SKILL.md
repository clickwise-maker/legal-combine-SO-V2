# Document Review Skill

## Overview

AI-powered document review for legal compliance.

## Capabilities

- Contract analysis
- Risk identification
- Clause extraction
- Compliance checking

## Usage

```json
{
  "skill": "review",
  "input": {
    "document": "contract.pdf",
    "type": "service_agreement"

}
```
