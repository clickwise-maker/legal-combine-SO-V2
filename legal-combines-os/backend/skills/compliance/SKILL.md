# Compliance Check Skill

## Overview

Automated compliance checking for Indian regulations.

## Capabilities

- GST compliance
- Company law compliance
- FEMA regulations
- SEBI compliance

## Usage

```json
{
  "skill": "compliance",
  "input": {
    "company_type": "private_limited",
    "checks": ["gst", "pf", "esi"]
  }
}
```
