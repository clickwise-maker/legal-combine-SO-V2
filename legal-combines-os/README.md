# Legal Combines OS

An AI-powered legal compliance platform for India.

## Features

- JWT Authentication with OTP
- Razorpay Payment Integration
- Lawyer/Typist Marketplace
- Government Law Scraper
- AI Legal Research

## Quick Start

```bash
# Backend
cd backend
pip install -r requirements.txt
uvicorn main:app --reload

# Frontend
cd frontend
npm install
npm run dev
```
